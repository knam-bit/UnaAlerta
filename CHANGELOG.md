## Convenção de commits

O projeto utiliza os seguintes tipos de commits:

| Tipo        | Utilização                          |
| ----------- | ----------------------------------- |
| `feat:`     | Nova funcionalidade                 |
| `fix:`      | Correção de erro                    |
| `docs:`     | Documentação                        |
| `style:`    | Alterações visuais ou de formatação |
| `test:`     | Testes                              |
| `refactor:` | Reorganização do código             |

### Exemplos

```text
feat: cria página de alertas
fix: corrige botão de alerta
docs: atualiza README
style: melhora layout da página inicial
test: verifica navegação principal
refactor: organiza código JavaScript
```

## Observação

As versões futuras deste arquivo devem ser atualizadas conforme o desenvolvimento real do projeto.

As datas, funcionalidades, correções, testes e commits devem corresponder às atividades efetivamente realizadas pela equipe no GitHub.

Os dados de monitoramento utilizados no protótipo devem ser identificados como **simulados** enquanto não houver integração com fontes oficiais.
